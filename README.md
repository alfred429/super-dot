# SuperDot

Version: 1.2.0 · 2026-10-31

Give your Dot a useful starting point for everyday life: a personal knowledge vault, a journal,
familiar life areas, practical skills and tools for making things.

Start on your phone. Let your connected Mac handle local files and creative work.
You bring your priorities; SuperDot supplies the foundations you can mould as you go.

## Start here

Point your Dot at this repository and ask it to follow [SETUP-PLAN.md](SETUP-PLAN.md).
The plan creates a private personal workspace from the supplied templates, preserves existing
work and introduces useful capabilities in small steps. Reuse accounts and tools you already have.

For the assistant: read the setup plan, then the relevant files it names. Reading this repository
provides instructions; actual installation, account permissions and scheduling use supported
features in the user's app. Explicitly load the relevant area/project instructions when working.

## What you get

- **A personal knowledge vault:** Personal, Family, Work, Hobbies, Money and Wellbeing.
- **Memory and reflection:** “Note it,” source-linked knowledge, morning prompts and evening journals.
- **Focused help:** brainstorming, Grill Me, Prompt Master, debugging, Ponytail and i-have-adhd.
- **Room to grow:** project starters, skill creation/vetting, research, routines and gentle vault care.
- **Connected creation:** Notion, Apple Keychain guidance, hosting, web research and Hyperframes.
- **Planning and content:** ClickUp, n8n social-media automations and Higgsfield premium media.

The [capability catalog](catalog/README.md) explains the collection and its upstream sources.
The skills follow one [macOS and writing standard](references/README.md#macos-and-skill-writing-standard).
Keep the whole package together so their supporting templates and references remain available.

## Try saying

- “Note it: I'd like to learn wildlife photography.”
- “Help me start a project for my portfolio.”
- “What is one manageable thing I can do today?”
- “Help me reflect on my day using the notes I've chosen to share.”

Conversation → knowledge → projects/actions → journal → next day's priorities → conversation.
One connected personal system, with links between areas rather than competing copies.

## Your information stays yours

Create the personal workspace outside this reusable source folder. Keep private notes there and
credentials in supported native stores/sign-in flows. The [ten agentic principles](templates/vault/AGENTS.md)
guide the assistant's work. Notion and public outputs receive only content you choose to share.

The Mac is normally on for local work. When unavailable, local filing waits; the assistant should
say what remains pending. Additional journal sources are opt-in, beginning with available chat,
then email/calendar and later supported services as you choose.

## Package status

This is a complete Markdown starter: templates, skills and tool guides. It contains no installer,
custom secret service or queue daemon. Actual Dot/Mac/iPhone compatibility and connected-account
actions still need a real run. Use the [short walkthrough](checks/README.md) when access is available.
