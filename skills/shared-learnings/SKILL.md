# Shared Learnings

## Inputs and context

Read the selected vault learnings and current [instruction-review reports](../agent-instruction-review/SKILL.md).
Use the person's permitted cross-project scope and actual schema. Local work follows the
[macOS guidance](../../references/README.md#macos-and-skill-writing-standard).
If source reviews are missing/stale, show that gap rather than claiming a complete comparison.

## Workflow

1. Group related lessons by the problem and reusable method, preserving links to their evidence.
   Deduplicate equivalent observations without deleting their original records.
2. Distinguish a local preference, a recurring cross-project pattern and a single important incident.
   Repetition supports generalisation but is not proof; name counterexamples and where the rule
   should not apply. A serious one-off can justify a proposal without pretending it happened often.
3. Save a concise synthesis through [Note It](../note-it/SKILL.md) in the schema-appropriate private
   location. Keep one working learning record with links rather than spreading full personal details.
4. Report which project/area/root instruction files might benefit, the proposed minimal wording,
   supporting sources, limits and tradeoff. Group common proposals so the user can approve once
   for explicit targets; retain unique project exceptions.

## Result and boundaries

Return the grouped learning report and recommendations, including “no general change warranted”
when appropriate. This skill does not automatically propagate instructions, publish lessons or message
other people/agents. Sharing outside the chosen private report scope needs separate authorisation.
Learning synthesis and instruction application are different actions: exact file edits require the
person's explicit approval. An approved change must preserve the prior version, respect parent
rules, update only named targets/mirrors and be inspected afterwards. No shared rule should expose
family, employer/client or project-private details merely because the method is broadly useful.
