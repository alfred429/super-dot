# Hobbies

Template version: 1.0.0 · 2026-10-31

Interests, hobbies, curiosity and learning at the person's own pace.

Read [AGENTS.md](AGENTS.md) for this area's assistant context. Start with notes here; add
`Knowledge/` or `Projects/` only when useful. Link related notes from other areas rather than
making a second working copy. Journal entries can link back to this area.

## Make it yours

- EDIT: Current priority — not set; leave blank until helpful.
- EDIT: Preferences/exclusions — private by default; add what matters here.

Example note: “Wildlife photography ideas.” If it becomes an active outcome, copy the vault's
`System/Templates/Project/` into `Life/Hobbies/Projects/Photography/` and personalise it.
Add a project link here after it exists.

An interest need not become a task. Do not turn leisure into a productivity target or infer buying permission.
