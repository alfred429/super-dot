# Project state

Template version: 1.0.0 · 2026-10-31

- EDIT: Goal — what useful result are we creating?
- EDIT: Scope — what belongs here and what does not?
- EDIT: Owner — who decides?
- State — proposed; this starter authorises no external action.
- Decisions — none yet.
- Next action — choose the smallest useful first result.
- Success — describe what we can inspect to know it worked.
- Sources — link related notes, references and outputs.
