# Obsidian — your personal knowledge vault

Version: 1.0.0 · 2026-10-31

Use an existing vault when suitable. Otherwise follow [SuperDot setup](../SETUP-PLAN.md) to create
the personal folder outside this source package. The user authorises the location and any merge.

1. Open Obsidian on the Mac. Install from [Obsidian](https://obsidian.md/download) only if needed
   and authorised.
2. Choose **Open folder as vault**, select the personal folder and open it. The
   [official vault guide](https://obsidian.md/help/vault) describes this native flow.
3. Open `README.md` and `index.md`. Confirm the six life areas are present and personalise the
   small marked fields. No community plugin is required for the starter.
4. Ask for a harmless Note It capture, inspect the note and retrieve it through the assistant.

Markdown files are the working knowledge; Obsidian makes them pleasant to browse/edit. Keep
sources, derived notes and reflections distinguishable using the supplied schema.

Phone access is optional. If wanted, choose an existing supported sync method using
[Obsidian's sync guidance](https://obsidian.md/help/sync-notes); explain any account/subscription
choice before enabling it. Sync is not a backup, and an exported snapshot is not live sync.
Preserve conflicting edits instead of selecting a silent last writer. Reuse the user's existing
backup method rather than adding another service as part of this starter.

Local filing requires Mac access. If unavailable, say waiting rather than saved; reading an old
synced copy does not prove a new capture reached the Mac.
